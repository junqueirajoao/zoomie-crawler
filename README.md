# Zoomie 🔍

Zoomie is an efficient, Python-based web crawler designed to quickly locate specific assets across a list of URLs. It scans target pages and isolates those containing your requested assets in seconds.

## ✨ Features

- **Fast URL Scanning:** Crawls multiple target pages rapidly.
- **Asset Identification:** Pinpoints exact URLs containing the assets you are looking for.
- **Simple Setup:** Lightweight Python implementation with minimal configuration needed.
